A native macOS cleanup tool

Measure,confirm,reclaim.

A development machine accumulates tens of gigabytes nobody asked for — build caches, archives, package stores, leftovers from apps you deleted months ago. Cruft measures all of it first, shows you the exact paths, and then moves only what you tick.

Nothing moves until you say so

No "one-click clean" button, no progress bar deciding on your behalf what was safe to delete.

  1. Measure

    See what each target actually costs

    Every cleanable directory is sized in the background before you touch anything, and re-measured after a run. Tasks whose CLI tool is missing grey out; a toolchain's row only appears if that toolchain's cache really exists on this machine.

  2. Confirm

    Read the exact paths, then tick

    An ⓘ button on every row lists the precise paths and commands that task will touch. The confirmation sheet spells out which of your selections can be undone and which cannot.

  3. Reclaim

    Into the Trash, with a way back

    File-based cleanups go to the Trash and leave a restore point. The footer reports what was actually freed, and a collapsible console streams the run live.

The biggest directories are the ones you never look at.

Developer caches

Xcode DerivedData, Archives, Products and old iOS DeviceSupport; CocoaPods; the npm, yarn, pip, SwiftPM and Gradle caches; the pnpm store; Cargo's registry; Go's build and module caches; the Maven repository. Plus scanners for stale node_modules trees and the installers still sitting in Downloads.

~/Library/Developer/Xcode/DerivedData
◍

System and leftovers

User-level caches and logs, Homebrew and Ruby gem cleanup, Docker dangling images, build cache, stopped containers and unused volumes, the Trash itself — and an app cleanup pane that finds what an uninstalled app left behind, matched by bundle ID.

~/Library/Caches · ~/Library/Logs · ~/.Trash

A maintenance console, not a magic button.

Everything it is about to do is visible before it does it, and everything it did is on the record afterwards.

Size estimates

Per-task disk usage, computed off the main thread and refreshed after every run so the numbers never go stale.

Per-task details

A popover on each row naming the exact paths or commands. No task does anything the popover didn't tell you about.

Live run log

A console pane, collapsed by default and auto-expanding during a run, streaming each file as it moves.

Restore history

Up to twenty batches of original-to-Trash path mappings, restorable in one click while the files are still in the Trash.

It moves files to the Trash. It does not delete them.

File-based cleanups go through the Trash and record a restore point, so a mistake costs you one click, not an afternoon. Cruft installs no privileged helper — a protected app is reported as a failure rather than escalated around. Targets stay in locations you own, never /Library or /System. Command tasks, emptying the Trash and Docker prune are the exceptions, and the app says so before you run them.

Build it, then grant it access.

Open source, no installer, no telemetry. Full Disk Access is the one permission it asks for, and it scans nothing until that check passes.
